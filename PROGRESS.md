### Подготовка пайплайна (до подключения Meshy)

  ручные правки → `content/voxels/<id>.json`.
- `npm run levels` собирает уровни из вокселей (прореживание и метрики — как для DSL).
- `npm run thumbs`: миниатюры фигур игровым рендером с трёх ракурсов + превью Meshy →
  `content/review/<id>.png`.
- В manifest — все 100 объектов Приложения А с сетками наборов и резерв А.4; учёт задач
  и кредитов — `tools/meshy-record.ts`; регламент — `docs/MESHY.md`.
- Автономная сборка для просмотра (`npm run release:preview`) и исправление шума флагов
  в шейдере.

**Проверки**

## Фаза 2. Играбельный прототип — готово, ⛔ контрольная точка

**Сделано**

- Рендер (`src/render`): один `InstancedMesh` на все кубы с атрибутами `aClue`, `aState`,
  `aColor`, `aReveal`; свой шейдер (фаска, швы, глифы по нормали грани, поворот глифов на ±Y к

  (`src/core/pick.ts`, сверен с эталонным «мелким шагом»).
- Камера: орбита, наклон −60…+80°, автокадрирование в свободную от HUD область, сброс вида,
  тряска при промахе.
- Управление: ЛКМ — инструмент, ПКМ — кисть, протяжка с фиксацией оси, вращение за пустое
  место/средней кнопкой, колесо — зум; тач: тап/протяжка, вращение одним пальцем по пустому
  месту, pinch-зум и вращение двумя; клавиши `Digit1/2`, `Space`, WASD/стрелки, `R/Q/E`, `Esc`.
- Инструменты и правила: молоток/кисть/«держите — кисть», протяжка (пропуск помеченных,
  обрыв на промахе, режим кисти по первому кубу), промахи (трещина, пометка, тряска, вибрация),

  окраски снизу вверх, «оживление» `bob/spin/hop/wobble`, название, звёзды, время, промахи,
  «Далее» / «Переиграть» / «В коллекцию»).
- Срезы: ручки у рёбер для X/Y/Z, кнопки «ось / − / +», клавиши; одна ось одновременно.
- HUD для портрета, ландшафта телефона и десктопа; пауза; `start/stop` геймплея платформы.
- Debug-API (`?debug=1`): выбор уровня, шаг/решение ботом, показ решения, FPS и draw calls.
