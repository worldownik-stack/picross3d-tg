# Фигуры из MagicaVoxel

Объект Приложения А можно не генерировать в Meshy, а нарисовать вручную в
[MagicaVoxel](https://ephtracy.github.io/) — бесплатно и с полным контролем над каждым кубом.
Пример — `home_09` «Домик» (`content/vox/home_09.vox`).

## Шаги для уровня `<id>`

1. В `content/manifest.json` у уровня: `"source": { "kind": "vox" }` (запись `meshy` убрать).
2. Нарисовать фигуру и сохранить в `content/vox/<id>.vox`:
   - в файле одна модель (несколько — объединить);
   - длинная сторона — не больше `maxSize` набора (Еда — 5–6, Дом — 6, …, Космос — 10);
   - ось Z MagicaVoxel — вверх; перед фигуры — сторона, повёрнутая к камере по умолчанию
     (Y = 0): в игре она смотрит на игрока на первом ракурсе.
3. Цвета — из палитры игры: первые 33 ячейки палитры в файлах, созданных инструментами
   (как `home_09.vox`), или палитра `content/vox/cube-sculptor.png` (`npm run vox -- palette`;
   положить в папку `palette` MagicaVoxel и выбрать в панели палитр). Чужие цвета импорт
   заменит ближайшими и напишет об этом; больше 6 цветов — редкие сольются с близкими.
4. `npm run vox -- <id>` → `content/voxels/<id>.json`.
5. `npm run levels` — уровень попадает в `public/levels/<pack>.json`, если решается логикой.
   Если нет — поменять форму и повторить с шага 4.
6. `npm run thumbs -- <id>` → `content/review/<id>.png`, проверить глазами.

Прореживание подсказок и оценка сложности — те же, что для Meshy-фигур.
